# GTL 1.20.1 全面压力验证（2026-10-08）

本轮对移植汇总提交 `11806a7478c78d0ad49e728230205c19db2bbe16` 进行压力验证。Java 17、Minecraft 1.20.1、Forge 47.1.3、AE2 15.4.10。独立压力 JVM 使用 G1、256 MiB 初始堆、2 GiB 最大堆、1 MiB 栈和 4 个可见处理器；重型模式顺序执行。未修改生产算法预算、测试断言或时间上限。

## 正确性与稳定性

首次全量构建执行 1,397 项普通测试：1,394 通过、2 失败、1 跳过。CP-SAT 冷启动 1/1、物料 DAG 冷启动 20/20 通过。两项失败分别为：

- `weightedFeedbackKeepsExternalConsumablesOutsideTheStateCycle`：补料期望 `{A=5}`，实际 `{A=8}`。
- `replenishmentPortfolioUsesTheExistingRefinementDeadlineWithoutQuarteringItAgain`：补料精修期间没有观察到预期的 DAG 组合搜索调用。

二者随后各在五个独立 JVM 中通过。首次失败仍保存在证据中；这说明尚有偶发稳定性问题，不能据重跑通过宣称根因已修复。没有为消除失败放宽断言或增加预算。

最终全量构建复跑为 1,396 通过、0 失败、1 跳过，耗时 228.274 秒；两组独立冷启动分别 1/1、20/20 通过。Forge 游戏内 auto / always 两种模式各 10/10 通过，均实际选择 V2，未见 Mixin 应用错误；always 模式确认 GTL stand-down。发布脚本 12/12、JAR 校验和 POM 生成通过。复跑通过没有消除首次失败这一事实。

## 复现与边界

新增可复用的 [批量随机库存夹具](../scripts/batch-benchmark/README.md)，可以在当前测试运行类路径上重新执行三个固定种子的 66,000 个案例。它独立计算期望库存，不复用规划算法作为 oracle；还保存提供者回调断言，避免被生产准入异常处理吞掉后产生假通过。

精简证据见 [gtl-full-stress-20261008.json](benchmarks/gtl-full-stress-20261008.json)，包含两轮全量结果、首次失败、独立复现、各压力 JVM 的耗时/内存/截断状态、夹具哈希和产物哈希。原始环境日志只留在本地忽略目录。

本轮没有加载完整 GTLCore/GTCEu/AE2LT 整包，也没有验证整包 TPS。频道使用真实 AE2 节点和连接配合合成 owner；存储独立进程使用显式 AEItemKey 解码，Forge 生命周期另由游戏内测试覆盖。EAEP 的真实 `ScaledMolecularAssemblerPattern` 可选协议测试因缺少对应 artifact 跳过，不能视为已验证。压力回放未发现稳定的库存或执行正确性错误，但首次全量失败和预算截断均是仍需关注的边界。
