# PR #12 规划器优化与 alpha 移植

## 实现

合入 PR #12 的有界规划器优化：发现完整材料 DAG 候选后立即回放，复用已完成的低宽度拓扑但逐次重建数量和库存边界；大图拓扑与回放采用索引遍历；整数预处理减少系数复制和临时对象，并保留精确溢出回退。CP-SAT 优先尝试小型种子见证和紧凑执行块，调度提示不增加约束，最终计划仍需独立执行证书。

Forge 保留当前材料排序掩码、普通/私有种子预留和同 ID 输入组修复。alpha 将原内嵌拓扑入口接入 `PlannerTopology`，保留 NeoForge 平台行为及原有预算。

## V2 耗时

沿用[既有语料清单](benchmarks/recipe-corpus-forge-1201-20261004/README.md)及[循环与小图基准](forge-1.20.1-alpha-planner-port.md)。ATM 目标为 `pneumaticcraft:kerosene`，NAST 为 `mekenergistics:me_supreme_combining_factory`，均使用 random20 库存、请求量 100,000 和既有 available-stock 语义。

每组按 before / after / after / before / after / before / before / after 串行启动 8 个独立 JVM，每端点 4 个，使用 `-Xmx3g -Xss16m`。大图每 JVM 预热 8 次、采样 8 次；小图预热 10,000 次、采样 4,000 次。大图、小图工作量设置均为 2,000,000，循环使用默认预算。先取各 JVM 样本中位数，再取 JVM 间中位数；计时排除读文件、构图及独立校验。

| 场景 | Forge 前 → 后 ms | 变化 | alpha 前 → 后 ms | 变化 |
| --- | ---: | ---: | ---: | ---: |
| ATM | 577.1852 → 569.6538 | -1.30% | 544.1468 → 554.8570 | +1.97% |
| NAST | 401.5737 → 394.5476 | -1.75% | 384.7184 → 381.8205 | -0.75% |
| batch-cycle 初测 | 24.1442 → 23.8840 | -1.08% | 20.6224 → 24.5903 | +19.24% |

循环初测每 JVM 每场景预热 40 次、采样 60 次。alpha 批量循环出现回退，因此另按相同顺序跑 8 个 JVM，每场景预热 160 次、采样 120 次，结果不与初测混合：

| alpha 长预热复核 | 前 → 后 ms | 变化 |

## CP-SAT 耗时

复用 PR 双分支共享种子回归图：每条分支用一个 S 生成 A，再运行消耗 R 并返回 A 的循环，最终汇合为 T。比较请求量 3 与一万亿。每次使用新规划会话，原生库初始化在计时外；每 JVM 预热 2 次、采样 6 次，每端点 4 个独立 JVM。

| 场景 | Forge 前 → 后 ms | 变化 | alpha 前 → 后 ms | 变化 |
| --- | ---: | ---: | ---: | ---: |
| shared-seed × 3 | 39.0484 → 8.4488 | -78.36% | 35.5714 → 6.9239 | -80.54% |
| shared-seed × 1,000,000,000,000 | 48.8277 → 23.5454 | -51.78% | 48.0198 → 19.3086 | -59.79% |

每平台、每端点、每场景的 24 个正式样本与 8 个预热样本全部可行且无缺料。小量独立执行回放；万亿量按原配方验证 seed-once / repeat-many 的符号执行顺序与精确次数。该收益适用于这两种结构，不代表所有 CP-SAT 请求。

## 正确性与结论

- Forge 基线与整合版各执行 192 个固定语料查询，可行性一致，两端合计 248 个可行结果均通过库存、物料平衡及原配方回放。6 个查询的执行次数或库存使用不同。
- Forge 4,000 个随机图对照可行性一致，两端合计 7,398 个可行结果通过独立材料、成本与多顺序回放。两例非可行结果的库存或补料变化另以独立 JVM 复核，补料后均可行且回放通过。
- 所有循环样本及长预热复核均保持 batch-cycle `{M3=1}`、shared-cycle `{M2=2}`，并通过补料重算与回放。
- ATM 计时样本的执行次数一致。NAST 在部分 JVM 出现两种实配方次数 862,205,949 / 871,172,469；Forge 基线与 alpha 整合版均有正式样本波动，Forge 整合版另有预热波动。保留所有慢样本及不利结果，不宣称计划完全一致或保证最优。
- 合并依据是 CP-SAT 种子场景明确的局部耗时收益，且 V2 长预热后的不利变化较小。循环分配量虽减少约 9%–18%，但本轮未测出游戏 GC 停顿或 TPS 收益，不以减少分配单独支撑合并。

这是离线规划测试，不代替游戏客户端、真实机器或服务器测试；TBR1 单产物投影也不等同于完整 AWR v3 多产物执行。本轮未重跑作者报告的 GameTest。

原始样本、源码/类/输入哈希、完整审查报告和复现脚本保留在本地忽略目录 `build/pr12-review/`；20 个基准输入文件在结束后复核哈希不变。开发日志不纳入提交。
