# GTL 无通道需求网络优化（2026-10-06，第五轮）

对比基线 `c339807`。发现阶段已经统计 `REQUIRE_CHANNEL` 节点；没有这样的节点时，不存在通往汇点的需求边，最大流必然为零。本轮在发现结束后直接返回网络成员集合和独立的空流量表，省去节点分裂、残量边、供给面、种子数组及回读表的构建。

仍保留完整的节点发现，用于最终覆盖电缆和连接的已用通道。空流量表对缺失键返回零，原版控制器面连接同样得到零流量。每次计算独立创建结果，后续新增设备时恢复完整求解。存在通道需求的网络沿用基线求解流程。

## 性能测量

使用真实 AE2 `GridNode` / `GridConnection` 构造合成网络；不启动游戏世界。Java 17.0.20、Minecraft 1.20.1、Forge 47.1.3、AE2 15.4.10，JVM 参数 `-Xms256m -Xmx2g -Xss1m -XX:+UseG1GC`。基线计算器、种子和残量核从 `c339807` 独立编译。

计时包含生产 `assignChannels` 的发现、构图、求解及回读，排除夹具创建和结果验证。每次检查完整网络成员、空获配集合、节点和连接零流量，以及缺失键的零默认值。旧版结果适配额外分配一个 32 B 对象，远小于本轮节省量。

同进程对比逐次交换新旧执行顺序，每图运行三个 JVM。无需求链和原版控制器网络每版本预热 128 次、测量 120 次；无需求网格预热 24 次、测量 40 次。独立 JVM 对比覆盖无需求链，每版本运行三个 JVM，逐轮交换启动顺序，预热 256 次、测量 120 次。p95 使用 nearest rank，汇总取三个 JVM 统计量的中位数。

## 正确性与版本验证

最终版本的通道定向回归 29 项通过。覆盖无需求网络、原版控制器面、跨次成员独立性、总需求超过整数范围，以及供给减少后的加权设备状态刷新；残量核还覆盖随机网络、深链、并行连接及重路由。

最终完整单轮运行：1,299 项测试中 1,298 通过、1 项因未提供可选 EAEP 运行时跳过、零失败；独立冷启动 CP-SAT 任务通过；发布 Jar/refmap 校验通过；GTL 兼容模式下 10 项隔离 Forge/AE2 GameTest 全部通过。

## 撤回的候选

子节点链表构造与种子供需汇总合并：梳状种子 p50 中位数下降 15.0%，但加权种子增加 144.4%；完整梳状重算 p50 仅下降 0.4%，p95 增加 10.3%。树形和网格也出现回退，未采用。

供需上界与连接回读合并：同进程测量没有稳定收益，梳状独立 JVM p50 中位数增加 30.8%；三轮批量当前线程 CPU 时间均增加，中位数从 13.79 增至 15.39 ms/次（+11.6%）。分别只保留供需上界或回读合并，也未显示稳定收益。两处改动均撤回，相关数据在 JSON 中标记为拒绝的候选，不属于最终版本。

此前候选的默认 JVM 完整验证曾出现规划器预算、补料和冷启动失败；复跑还出现原先通过用例的 3 秒超时。完整失败和复跑摘要保留于 JSON。最终无需求优化在上述固定验证 JVM 下获得完整单轮通过，不把多次复跑的逐项合并结果当成单轮通过。
