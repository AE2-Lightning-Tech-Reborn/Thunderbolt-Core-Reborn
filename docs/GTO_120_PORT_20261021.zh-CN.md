# 上游 1.20.1 移植与 GTO 实测（2026-10-21）

选择性移入上游 Forge `1.20.1` 的两个提交，保留当前 Minecraft 1.20.1 / Java 21 / Forge 47.4.20 / GTOCore 26.10.5 / AE2-GTO 15.2610.8。NeoECO 继续移除，不合并后续两个 NeoECO 提交，不覆盖当前 GTO 计算入口、原生回退和第三方摘要兼容。

## 实现

- [ca6d2ab](https://github.com/AE2-Lightning-Tech-Reborn/Thunderbolt-Core-Reborn/commit/ca6d2ab40b85f35c792421f9ee3aae89b7ab063b)：移入普通 long 存取路径、按通道维护的原始类型数组、精确数量快照、NBT 快照、SavedData 缓存及服务器停止时释放缓存。保留有限盘容量、126 位和任意精度存储，模拟操作不改变摘要或库存。
- [07f7883](https://github.com/AE2-Lightning-Tech-Reborn/Thunderbolt-Core-Reborn/commit/07f7883fb3dd5c35649abbf3185ef8df35330846)：`BigCraftingPlanner.Result` 保留诊断计划，提取 `ExactCraftPlan.byteCost(...)` 供报告读取完整中间需求与成本；使用 BigInteger，混合单位累加后统一向上取整。保留旧三参数构造器及可执行条件。预览继续使用 GTO 的 fastutil 构造接口。
- 保留当前已有的 GTO 容量修复：类型上限、相邻 63 位容量借位、已占用字节的剩余单位、插入元数据进位和提取借位。上游普通 Forge 的旧容量公式没有覆盖这些修复；新 Channel 布局已与当前公式合并。`hasCurrentUnits()` 继续公开，保留换算率变化后的库存与摘要同步。
- 同步上游相关回归，并补充旧结果构造器和非驻留、自定义相等键的查找测试。上游假定同内容 AEItemKey 为不同对象；GTO 会驻留物品键，因此物品测试按实际身份行为断言，另用独立自定义键保留不同对象的相等查找覆盖。旧缓存条目计数断言随布局更新，数量和容量断言不变。
- 清理中英文 README 遗留的 NeoECO 支持描述。当前生产源码、构建配置及发布包没有 NeoECO 引用，材料缓存同步 coremod 保留。

## 构建与回归

针对性回归：188 项，187 通过、1 项实际 EAEP 制品测试跳过、0 失败。

完整 `check`：1543 项，1542 通过、1 跳过、0 失败。其中主套件 1520 项（1519 通过、1 跳过），另有 23 项独立冷启动/重放测试通过。针对性套件与完整检查重叠，不相加。

四个固定随机种子各执行 250,000 次混合 long/BigInteger 存取，覆盖三个盘、1024 个键、反复保存和重载，独立账本确认逐键守恒。文件压力测试覆盖 16,384 个键、512 位数量、12 代存档、24 次文件保存、压缩及 ID 复用；保存后的历史快照不随后续存取变化。大数报告覆盖 Long.MAX_VALUE 两侧、百位数量、混合单位、容器返还和工具成本。

首次回归的三项失败来自旧条目计数和物品键身份假设，上述适配后通过，原失败 XML 和日志保留。`compileGameTestJava`、`verifyReleaseJar` 和 `git diff --check` 均通过。

## 实际服务器

隔离端口 25610；未安装 NeoECO；配套 AE2LT 2.1.2-gto.1。生产依赖与前次测试一致；未修改相邻 LT 项目或正常游戏实例。

先用移植前的 TB 生成旧存档，再换新包读取、保存并再次启动同一世界。两次新包的重启探针均通过：151 位物品数量、101 位流体数量、两个 63 位数量段、模拟不修改库存、提取返还及输出端持久化均准确。真实供电驱动器测试覆盖 16,384 个 NBT 键、512 位数量、原生/闪电/可重载通道、模拟和实际存取、独立账本、SavedData 往返、摘要以及换算率 8→17→8。
