## 更新内容

- 移植上游库存感知的执行次数优化、普通配方双/三路线分配、上游批次替换、末端多路线优化，以及输入、材料足迹、可生产顺序与预处理复用。

- 修正整合入口：初始方案不消耗库存也能继续优化；恢复工作量被拒绝时同时标记计划与诊断；通用混合批次阶段接收会话共享工作量回调。
- 本地 `COMPLETE` 只证明既有库存提取域内的最优性。只有原图普通库存与初始提取域完全相同、且未使用目标库存时才跳过通用阶段，避免隐藏使用更多现有库存的更少执行方案。

## 库存策略变化

执行次数减少时，可使用快照内其他普通库存，或增加某种已有材料的用量；仍不得越库提取。执行次数相同时，必须不增加任一种材料提取，且改善库存用量或净资源损耗。有状态配方与宿主私有可复用库存限制保留。

例如 `8T ← 12raw`、`2T ← 3raw` 请求 19：只有 30 原料时，混合两种配方得到 20T，执行 4 次；有 36 原料时，可以执行大配方 3 次得到 24T。这是新的执行次数优先策略，不是库存越界。旧混合配方回归改为明确只有 30 库存，仍检查两种原样板及精确提取；另外新增 36 库存的三次执行回归。

两项无效 oracle 回归显式拒绝独立批次搜索的工作量，隔离检查无效候选不能替换已认证计划；独立批次搜索的有效候选仍由其他回归与压力测试覆盖。

## 验证

环境：Java 17.0.20、Minecraft 1.20.1、Forge 47.1.3、AE2 15.4.10、GuideME 20.1.15。未同步 GTL，也未引入 NeoForge、AE2 19 或 Java 21 API。

- `test build`：1133 项，1132 通过、0 失败、1 项需要可选 EAEP 运行时的测试跳过；`check` 另通过独立 JVM CP-SAT 冷启动回归。重混淆、JarJar 与 `verifyReleaseJar` 通过。
- 独立压力：279 项全通过、无跳过，包含实际 EAEP 1.6.3 协议测试。10 个独立 JVM 各运行 32 个 CP-SAT 新会话，缺料、预算耗尽和无效证书均为 0。
- 固定种子 30000 个双路线材料平衡样本、30000 个路线诊断样本、6000 个不同库存/万亿缩放样本，本轮未发现无效计划或少执行参考解遗漏；这不构成任意图全局最优保证。
- 16 线程 16000 次固定链规划、16000 个混合会话/48000 次数量探测，未发现库存污染；60000 次发信器切换、精确存储及反复增删/持久化、通道回归通过。6000 个三至六路线独立穷举样本包含预期耗尽场景，未错误声称完成。
- 游戏验证：9 个场景 × 3 个独立 Forge JVM，27/27 通过，每轮确认实际游戏完成标记和全部场景日志。覆盖分子装配室、双路线、三路线、缺料预览，以及有/无请求方的不同库存优化。请求方精确收到 19 个产物，多余 5 个留在 ME；原有 19 铁不动、实际消耗 27 钻石，CPU 完成且请求清空。
- 发布包包含 481 个生产类，全部 Java 17 字节码，类名集合与编译输出一致；许可证、Mixin 配置/refmap 和 MixinExtras 内嵌依赖校验通过。

初次构建遗留的合并标记、整合期间旧策略断言和测试夹具假设失败均保留在本地日志中；最终结果来自修正后的独立完整构建，而非删除或跳过失败测试。验证期间生产源码未改动。
