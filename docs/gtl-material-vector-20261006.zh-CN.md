# Forge 1.20.1_GTL：宽副产物图的完整方案校验

本轮以本地提交 `e603fc3` 为基线，修复独立原料分量全部求解完成后，最终校验仍可能因局部可选时间片到期而丢弃完整方案的问题。开发与验证保留在本地。

## 实现

`tryIndependentRawStock` 的可选时间片只包围分量分析与求解。完整计数向量离开该时间片后，执行全图库存、主产物需求和拓扑校验；调用方的取消请求、截止时间及外层补货探测时间片继续生效。分量未全部完成时仍走原有回退。没有增加求解预算或测试超时。

`MaterialDagReplay` 的二部拓扑图改用整数节点及数组邻接表，替代包装节点、逐节点哈希集合和装箱入度计数。重复边逐条增加及减少入度，保持线性复杂度；物料数量仍使用 `BigInteger`，原始输入边和自循环检查保留。

新增四项回归，覆盖恢复外层截止时间、最终校验中的调用方取消、重复输入边的精确消耗，以及自输入配方的聚合证书拒绝。

## 对照方法

Java 17；每个版本分别运行三个独立 JVM，交替版本顺序。最终校验单独测量，请求量分别为 1 与 10¹²，每个 JVM 预热 3 次并采样 12 次。完整 4096 分支规划每个 JVM 预热 1 次并采样 5 次，调用方截止时间为 15 秒。普通规划场景采用原有压力夹具。

计时和线程分配量测量均不包含独立供给顺序重放。重放使用精确整数，核验真实库存、每步输入与目标产量。缺失方案加入其声明的缺失物料后再重放，单独记录为未完成；这些样本不会被删除，也不会用于宣称等量完成工作的性能收益。压测与 Gradle/GameTest 分开运行。

最终校验在两种数量下分别减少 39.3% / 65.4% 的中位耗时与 37.8% / 31.4% 的分配量。完整规划的新版本 30 个测量样本及 6 次预热全部可行；基线有 1 个万亿数量的测量样本和 1 次预热返回缺失，均没有预算耗尽标记。所有完整和缺失样本均通过相应的独立重放。万亿数量的完整规划数据包含未完成样本，不能据此宣称等量完成工作的提速百分比。

普通场景除准入夹具外均可行，准入夹具两版本各 36 次测量均按预期退出预算。会话和长链的耗时在 JVM 之间波动明显，本轮不将其归因为已证明的调度噪声，也不隐藏较慢的结果。原始采样与未完成记录见配套 JSON。

基线运行新增的截止时间回归时，确定性地命中“最终校验仍携带局部截止时间”的断言；本轮通过同一回归。

受影响的 `MaterialDagSupplyTest`、`MaterialDagBudgetTest`、`MaterialDagReplayCancellationTest` 共 **35 项通过，0 失败**。发行 Jar/refmap 检查通过；Forge 47.1.3、Java 17、强制 `gtlCompat=always` 的真实 AE2 集成 **10 项 GameTest 全部通过**。

全量验证本轮没有通过。第一次执行到 342 项后测试进程退出 -1，连接重置，已有 CP-SAT 共享种子补货断言失败；第二次日志观察到 952 项（946 通过、5 失败、1 跳过）后进程结束，没有完整构建结尾或新的完整 XML 报告。失败包括两项 CP-SAT 预算断言、一项原有补货时限探针，以及两项依赖旧拓扑 `HashMap.merge` 的取消探针。取消探针已改为验证数组拓扑的实际遍历检查点，并在最终定向验证中通过。

另一次 53 项定向验证出现 25 项失败，其中多数 CP-SAT 返回 `INVALID`。基线与新版本均在独立 JVM 中复现 `UnsatisfiedLinkError: com.google.ortools.util.mainJNI.new_Domain__SWIG_2(long,long)`，使用隔离的原生库搜索目录仍然如此。系统盘随后只剩约 7 MiB，导致 Gradle 缓存打包及启动失败；仅清理可重新生成的构建缓存条目后，35 项相关测试与发行包验证通过。释放空间后 JNI 错误依然复现，因此其根因尚未证明；本轮不将其归因为已修复的磁盘问题。

最初 72 项定向测试有 7 项失败。两个新增探针逐检查点收集完整调用栈，干扰局部时间片；最终改为只观察目标键在校验中的哈希访问，普通求解检查点没有探针开销。另有原有 1 秒场景在独立对照中基线通过、本轮超时，但在全量运行中通过，这一不稳定观察也保留。

最终发行包：`build/libs/thunderbolt-forge-1.20.1-2.0.0.jar`。SHA-256：`14a2ea783289f4eb49d3462960dfe5374367ce0aa75d6719f2f08c0574ca659a`。

扩大验证完成 **1249 项：1208 通过、40 失败、1 项可选 EAEP 跳过、0 错误**。临时筛选只排除主 planner 包的 `CpSat*` 测试类，其他包及测试中的 CP-SAT 调用仍运行，因此它不能称为完整的非原生测试集。失败包括原生绑定/能力测试、两个启用 CP-SAT 的模糊输入用例、原有补货取消探针，以及终端批量回退的原子预算断言；最后一项与本轮修改的关系尚未证明。本轮不声称通过全量测试。最终 35 项定向验证的 XML 已独立保存，未被扩大验证覆盖。

原始本机日志只保留在忽略的 `build/` 目录，配套 JSON 不包含本机路径或凭据。
