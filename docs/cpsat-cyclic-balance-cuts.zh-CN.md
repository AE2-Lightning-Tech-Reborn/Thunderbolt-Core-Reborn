# CP-SAT 环内整数传播退化修复

## 问题

少数小图即使只请求 1 个产物，也会耗尽 CP-SAT 时间预算。它们很快就找到了补料方案，但无法快速证明缺料下界。变量域保留 long 数量范围，环上的局部边界传播可能逐次收紧。

固定一个真实模型，只改变诊断用整数域上限 U，搜索分支一直为 5，整数传播次数从 U=10^4 时的 22,589 增长到 U=10^7 时的 22,500,148，呈近似线性增长。缩小变量域仅用于定位，不能直接作为修复，否则可能丢失有效方案。

## 实现

在桥接模型中保留两类现有约束的索引：材料余额下界、主产物需求上界。`CpSatBalanceCuts` 在同一环分组内，寻找符号相反的共享配方变量，将两个约束按正整数倍相加以消去它。

若共享变量的系数是 a>0、b<0，两行分别乘以 `-b/gcd(a,b)`、`a/gcd(a,b)`。新行是现有约束的非负组合，因此原整数解全部保留。所有系数、常数和乘法先用 BigInteger 计算；除以系数公因数时，整数下界向上取整。

只保留配方变量更少、且所有剩余配方系数均非正的组合。它们直接表达材料消耗下界。仍含正向内部产出的组合可能增加求解器的无效搜索，实测会使少数限时案例返回带巨大无用循环的候选，因此不加入。

新增处理具有固定结构预算：最多检查 4096 个行对、尝试 4096 次消元、添加 128 条约束；没有新增数量变量，也不缩小任何变量域。可能超过原生 int64 安全范围的组合直接跳过。达到结构上限只会少加冗余约束，不会判定不可执行。

原有自增环准入、主产物需求、补料边界、执行证明和超时返回规则继续生效。新增组合使用实际建模的批次余量、有限使用工具及催化剂项，不能把这些项删掉后套用普通材料公式。

## 两类回归

第一类需要合并两种材料的余额，抵消内部循环，直接推出至少缺 q 个 M0。第二类需要把 M1 的副产物余额与 M3 的主产物需求约束合并，证明在不主动制造无需求主产物的规则下，至少缺 q 个 M1。

`CpSatQuantityPropagationTest` 对两个原始小图测试 1、10^6、10^12 的目标与库存，同时颠倒样板顺序，要求得到正确缺料、完成最优性证明、不进入可选 Petri 细化，并确认补足材料后可执行。另保存两张限时搜索图，防止小额缺料被巨大的无用循环替代。

`CpSatBalanceCutsTest` 独立枚举 100 组加权整数系统中的小域赋值，核对原来的每个解都满足新增约束；同时检查溢出跳过、条件约束隔离、变量域不变和大环生成量上限。

运行：

```shell
./gradlew test --tests '*CpSatQuantityPropagationTest' --tests '*CpSatBalanceCutsTest'
./gradlew build
```

本次完整构建共 620 项测试通过。固定同一批 43,000 张小图，独立检查 43,000 份初始计划和 14,456 份补料重算计划，均可执行；原来可行的请求没有变成缺料。该语料中预算触顶计划由 235 份降至 200 份。

两类慢例在原生加载及预热之外各重复 3 次，完整规划耗时中位数如下，单位为毫秒。数量与库存同比放大，配方系数不变。

| 小图 | 数量 | 修复前 | 修复后 |
| --- | ---: | ---: | ---: |
| 主产物余额环 | 1 | 2455.35 | 1.86 |
| 主产物余额环 | 10^12 | 2456.98 | 1.94 |
| 副产物与主需求环 | 1 | 2445.29 | 1.62 |
| 副产物与主需求环 | 10^12 | 2445.74 | 2.13 |

修复前这四组均耗尽预算，修复后均完成最优性证明，所报补料保持一致。其他对照图也完成了 1～10^12 的 216 次数量实验。性能数据是本机观察值，不作为跨机器的时间承诺。

这项处理消除了已复现的局部传播退化，并不声称任意复杂环或整数规划问题都能在多项式时间内完成。
