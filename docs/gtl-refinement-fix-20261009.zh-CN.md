# 补料认证与限时测试修复（2026-10-09）

本轮修复[首轮全面压测诊断](gtl-refinement-failure-diagnosis-20261008.zh-CN.md)定位的两项问题：小循环补料依赖可选重规划，可能从必要的 `A=5` 退回保守的 `A=8`；预算测试要求限时搜索必达组合搜索路径，可能把合法提前退出判成失败。

## 小循环直接认证补料

`CraftPlannerV2.rechecksReplenishment` 先对补料后的图认证已有执行次数向量。原物料 DAG 证书不接受循环时，规模允许的图继续尝试现有 `MaterialDagReplay.trySmallPlan`；证书成功后保留候选，无需再次进入可选重规划。

小循环证明仍要求所有可执行顺序都能完成，原有边界保持相同：可达图工作量最多 128、最多 16 个配方、64 次执行、4096 个证明状态。私有可复用库存保护、原始配方身份校验和外部取消传播仍由已有逻辑处理。

新增回归关闭可选重规划，直接检验补料与库存：

| 原库存 | 目标 | 正确缺料 | 可选补料探测 |
|---|---|---|---:|
| 1 A、2 raw | 2 T | 5 A | 0 |
| 5 A、2 raw | 2 T | 1 A | 0 |
| 1 A、0 raw | 2 T | 5 A、2 raw | 0 |

配方为 `3A → 2B` 和 `3B + raw → T + 4A`。新增前两项测试在旧代码上分别稳定返回 `A=8` 和 `{A=8, raw=2}`，修复后通过。测试同时检查补料后用最小搜索预算重新规划可行；新增取消测试确认从小循环补料证书抛出的外部异常原样传播，并恢复调用者作用域。

## 预算策略独立于路径必达

组合搜索的原时限计算提取为生产调用的会话方法，预算数值保持相同。普通发现仍只使用父作用域剩余时间的四分之一；补料探测使用父作用域剩余时间，同时受累计 100 ms 上限约束。

预算回归直接检查父时间、累计已用时间、普通搜索预留和耗尽后的零额度，不再依赖 100 ms 内一定观察到组合搜索。取消测试从真实缺料精修 oracle 进入组合搜索首个检查点，稳定检验外部异常传播。过期精修测试继续要求精确保留 `M2=6`、补料重计划可行和资源平衡；其观察器只在可选作用域变化时检查调用栈，减少热检查点观测开销。其他较小补料集成测试保留。

## 验证结果

环境为 Java 17、Minecraft 1.20.1、Forge 47.1.3、AE2 15.4.10。

| 验证 | 结果 |
|---|---|
| 修复前新增回归 | 2/2 失败，稳定复现旧缺料向量 |
| 修复后定向回归 | 163/163 通过 |
| 完整构建 | 1399 通过、0 失败、1 跳过；构建及发布 JAR 验证通过 |
| 独立冷启动任务 | CP-SAT 1/1、DAG 回放 20/20 通过 |
| 独立 JVM 重复回归 | 280/280 通过；每个方法独立启动 JVM 后重复执行 |
| 循环压力回放 | 12 场景、144 次测量及 36 次预热；0 回放失败、0 无结果；144 次预算截断 |
| 4 线程持续压测 | 1600 次测量及 320 次预热；0 异常、0 不完整结果；800 次预算截断 |
| Forge 游戏测试 | `auto`、`always` 各 10/10 通过；确认 V2 选用，0 Mixin 注入失败 |

多线程测量的 P50/P95 为 5.78/9.65 ms，最大 22.22 ms；五轮后 GC 存活堆增长约 0.11 MiB。循环场景覆盖 2、4、8 个反馈环，需求量 3 与 `10^12`，以及缺少一个启动材料的情况；按返回补料向量执行的独立压缩资源回放均通过。复用的压力夹具在预算截断时跳过额外补料重规划，本轮 72 次缺启动材料测量均走此分支；小循环补料重规划由新增回归另外验证。循环结果为 `CUTOFF`，多线程中也保留预算截断计数：这些数据证明本轮场景的可执行性，不证明全局最优，也不构成长期无泄漏证明。

精简证据及本轮生产代码、测试、夹具与发布 JAR 哈希见 [gtl-refinement-fix-20261009.json](benchmarks/gtl-refinement-fix-20261009.json)。发布产物按本轮 Maven POM 的 `2.0.0` 版本定位，未使用目录中的历史 beta 包。JUnit 可通过 `./gradlew test --tests '*ReplenishmentCertificateTest' --tests '*MaterialDagBudgetTest'` 复验，完整构建使用 `./gradlew build`。

## 剩余边界

唯一跳过项需要未提供的真实 EAEP 可选组件。游戏测试包含强制 GTL stand-down，但未安装真实 GTLCore，不代表完整 GTL 整包的 TPS 测试。

大型或不支持小证书的循环向量仍使用限时重规划及安全回退。本轮未调整可选质量截断与主搜索预算耗尽的分类，也未声称消除所有预算波动。首次失败进程缺少阶段记录，其具体 GC、JIT 或调度触发事件仍无法确定。原始日志、类路径和本地验证脚本保留在忽略目录，历史失败证据保留。
