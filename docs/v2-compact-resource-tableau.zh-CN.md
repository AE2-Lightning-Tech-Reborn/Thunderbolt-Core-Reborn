# 原料约束的矩阵压缩

普通多原料备选配方可能同时受到两处过早限制：依赖边界超过 12 个材料，或者整数预处理已经从原料库存推出执行次数上限，矩阵又为每个变量重复加入同样的上限行。

无需额外顺序校验的组件现在由实际变量数、约束数及预处理后的矩阵容量决定准入。需要种子、返还物等顺序校验的组件维持原有结构限制。16,384 个矩阵单元、2,097,152 单位共享工作量及 64 个整数搜索节点等上限均未提高。

对于非负变量，保留的原料行 `-a*x - b*y ≥ -c` 自身就能推出 `x ≤ floor(c/a)`。只有该上限不弱于完整预处理上限时，才可去掉 x 的独立上限行。用于证明的原料行必须保留，即使原来的区间预处理认为它冗余。变量下界平移后重新计算行的右端量；有限数域中更紧的上限仍然保留。

只有原始矩阵因容量超限而无法开始求解时才使用压缩。原本能够容纳的模型保持已有单纯形基与选轴顺序，避免无必要地改变有限预算下的搜索结果。

验证包括低容量矩阵、原料行与独立上限不能同时删除、有限数域、下界平移、512 组独立穷举对照，以及双原料备选配方的库存平衡、单位/万亿数量和真实缺料后的重新规划。
