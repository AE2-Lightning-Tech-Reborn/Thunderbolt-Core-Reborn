# Forge 1.20.1 按实际环境同步上游

本页记录同步时的验证状态。后续双配方反例优化见 [混合批次优化](mixed-batch-optimization.zh-CN.md)，不将历史失败记录当作当前结果。

最新同步与库存策略变更见 [上游库存感知更新](stock-aware-upstream-update-20261004.zh-CN.md)。以下 `28a1f25` 的策略、测试数量及失败记录均为历史状态。

同步基准：`upstream/1.20.1@28a1f25`，库存优先修复参考 `upstream/main@764eee0`。保留 LGPL 许可证和原有署名，不修改模组版本号，不同步 GTL。

## 同步与保留

- 合成优化器采用上游完整的执行次数优先方案：全局成本势、可执行性传播、局部区域候选、下界剪枝、多轮策略及撤销配方。
- 会话改用上游 `IndexCache`；库存限制、数量和传播状态不缓存为共享可变数据。
- 默认优化上限 2.8 s，500 ms 无至少 1% 执行次数收益则停止；最多 32 次探测。保留本地 `thunderbolt.maxConsumptionOptimizationNanos` 设置入口，仍受外层期限及共享工作量限制。
- 删除未接入实际路径的整图探测次数门槛，恢复上游宽图局部探测及预算不足回归。探测按局部图规模收费，而不是完整整合包规模。
- 保留本地 `OptionalPlanningStages` 拆分、`PlannerTopology` 迭代 SCC/拓扑排序，以及可选耗尽保留已完成计划、外部取消继续传播的边界。
- 保留已移植的库存优先、大整数预览、AppliedE Forge 0.14.3 正确包名及真实 JAR 测试。Useless 保持移除，EAEP 与 NeoECO 按真实 1.20.1 API 能力加载或降级。
- 通道、存储、批量执行、provider cache 已与 Forge 上游一致，不重复改动。补入上游历史 Forge 移植说明；通道回归只是文件/类名不同，不重复添加测试。
- 不直接移植 NeoForge、1.21 data-component 或不存在的 Useless API；版本仍为本地 `2.0.0-beta.5`，不因源码同步宣称正式发布。

## 目标与限制

候选不能增加既有库存提取或改变有状态配方次数。在该约束下先比较执行次数，再比较资源；不再接受为节省少量资源而增加机器执行次数的候选。随机测试的独立参考目标也相应调整，并保留材料平衡和可行性检查。

有限搜索不保证全局最优，Issue #5 的混合配方反例仍须单独记录；同步不能当作该问题已解决。JVM 回归、压力和真实可选协议测试不能代替游戏内多方块及合成提交验证。

## 验证结果

- Java 17.0.20 / Minecraft 1.20.1 / Forge 47.1.3 / AE2 15.4.10。
- 全量 `build optimizationBenchmark`：909 项回归，908 通过、1 项因未提供可选 EAEP 运行时而跳过，`verifyReleaseJar` 通过。
- 首轮全量 CP-SAT 死锁替代路线测试曾失败；该组独立复跑 8 项全通过，第二轮完整测试也通过。保留首轮失败记录，不能据复跑断言时间预算波动已修复；未更改 CP-SAT 生产代码或排除该项正常回归。
- 独立压力及实际 EAEP 1.6.3 协议 15 项全通过，无跳过；时间上限 JVM 覆盖及最小值测试 1 项通过。
- 发信器切换 2000 组、6000 次计算，库存分配差异为 0；8 线程 4000 次规划、2000 层链、最大数量 10^12，以及 10 万次最高 500 bit 存储操作、100 次持久化往返通过。
- 固定种子 3000 个双配方样本没有材料平衡/可行性错误，但仍有 228 个非最少执行次数结果，其中 10 个有不增加当前库存消耗的更少执行参考解；不把这些结果算作全局最优。
- 已知混合配方单独诊断仍失败：8T←12raw 与 2T←3raw 请求 19，实际 10 次/30raw；独立参考为两种配方各两次，共 4 次/30raw。这是保留的既有非全局最优限制，不混入通过的正常回归统计。
- 发布包保留 LICENSE、Java 17 字节码、IndexCache，且无旧 TopologyCache 或 Useless 类；版本号不变。测试和详细日志只保存在忽略的 build 目录，不加入源码提交。
