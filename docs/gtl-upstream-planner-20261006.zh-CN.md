# 上游 1.20.1 规划器优化继续移植（2026-10-06）

上游锁定的 `1.20.1_GTL` 本次没有新增提交；通用 `1.20.1` 分支在本地上次移植点 `59811d1` 之后新增了 `9b91100` 和 `f165e2a`。本轮将这两批 Forge 1.20.1 规划器优化移植到 `1.20.1_GTL`，没有修改 GTL 调度、频道回写或版本配置。

移植内容包括精确有理数的整数/同分母快捷路径、原始资源权重缩放快捷路径、加权执行次数的长整数快速求和；规划器还延迟分配递归回退状态，复用可达图和消费者拓扑表，复用成本传播的环形队列与临时数组，并减少单路由排序和状态扫描。新增测试覆盖大整数分数、成本传播缓存、取消后拓扑重建、不同区域大小复用、加权执行边界和延迟状态初始化。

## 验证

定向规划器与频道回归全部通过，包含精确分数、成本传播、取消重建、加权成本、随机网络、深链、并行连接及供给状态刷新。

完整 Forge 1.20.1 验证使用 Java 17.0.20、Forge 47.1.3、AE2 15.4.10，验证 JVM 为 `-Xms256m -Xmx2g -XX:ActiveProcessorCount=4`：1,307 项测试中 1,306 通过、1 项因未提供可选 EAEP 运行时跳过、0 失败；独立冷启动 CP-SAT 通过；发布 Jar/refmap 校验通过；强制 `gtlCompat=always` 的 10 项 Forge/AE2 GameTest 全部通过。

压测基线为 `59811d1`，旧规划器从该提交独立编译；当前规划器使用工作树源码。每个版本运行三个独立 JVM，交替启动顺序；每个 JVM 预热 3 次并测量 12 次，包含真实规划请求、结果重放校验和线程分配统计。结果排除夹具创建，保留 12 样本的 nearest-rank p95，并取三个 JVM 统计量的中位数。
