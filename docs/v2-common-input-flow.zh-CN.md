# 共同消耗与原料分配

单原料网络流不能直接表示 `A + 燃料 → P`、`B + 燃料 → P`。但两条路线对燃料的消耗相同，可以先扣除固定消耗，再解决剩余的 A/B 分配。

`CommonInputFlow` 只接受直接消耗天然原料的普通配方组件：没有副产物、返还物和私有复用，组件产物不被内部配方消费，同一产物所有备选配方的输出批量相同。这样，先减去产物库存与外部供给后，各产物需要的总执行次数是确定的。

对每个产物逐项提取所有路线共同消耗的最小数量，将它乘以所需执行次数，计入固定边界消耗。同一种原料既可参与固定消耗，也可参与可选消耗；二者共用实际库存，不能各计算一份。重复输入槽先按材料合并。

提取后，如果每条路线只剩一个消耗输入，并满足材料固定批量条件，就交给已有稀疏整数流内核。如果一条路线没有剩余消耗，它在该产物上支配其它路线，直接固定使用它。其它结构回到通用路径。

投影中的输出单位表示一次原始配方执行，所有结果必须恢复原始配方身份与次数。缺料候选仍经过原始完整 DAG 余额校验及补料重算，不将投影直接导出。工作量与取消控制继续使用同一份预算。

测试使用原始配方执行次数穷举对照可行性及补料不可支配性，覆盖产物余数库存、共同原料同时作为可选原料、固定燃料不足、边界共享库存及不符合准入条件的图。大型已知可行分配在单位与万亿数量下核验完整原始余额和库存上限。
