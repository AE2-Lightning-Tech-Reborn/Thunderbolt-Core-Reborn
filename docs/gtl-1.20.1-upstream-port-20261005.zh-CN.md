- Minecraft 1.20.1、Forge 47.1.3、AE2 15.4.10、Java 17 不变，GTL 分支版本号仍为 `2.0.0`。

## 后续修复：关闭 CPU 让位时的规划等待

核对 GTLCore 的 `simulateFor()` 覆盖后，发现 `gtlCompat=never` 会把 Thunderbolt 的候选等待切回 AE2 monitor，而 GTLCore 不再执行对应唤醒，导致候选尚未结束时计算任务可能永久等待。

改用独立的 `usesGtlCalculationScheduler()` 判定：GTLCore 在场时始终轮询；没有 GTLCore 时仅 `always` 强制轮询。CPU 派发开关维持原语义。补充三种模式的判定回归，以及直接调用生产等待回调的返回和中断回归；JUnit 运行时显式提供 MixinExtras common，因为普通测试进程不会解包 Forge 内嵌依赖。

Java 17 / Forge 47.1.3 / AE2 15.4.10 下，26 项针对性回归全部通过；完整 `test build` 共 1,278 项，1,277 通过、1 项可选运行时测试跳过，无失败或错误。独立冷启动 CP-SAT 与 `verifyReleaseJar` 通过。完整 GTL 整合包的验证边界仍如上所述。
