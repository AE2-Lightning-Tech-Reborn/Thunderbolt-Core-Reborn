# Thunderbolt Core 2.0.5 (Forge 1.20.1)

对比版本 / Compared with: `1.20.1-2.0.4`

## 中文

- 修复与 ElementalCraft 同时安装时，进入世界出现 `IncompatibleClassChangeError: ... must be Methodref constant` 的崩溃；调整 EJECT 能力拦截范围，避免 Forge 公共父类上的 Mixin 冲突。
- 改善小型合成图的补料兜底方案选择，在规划预算内比较可认证的直接路线，保留取消与时间预算约束。
- 优化库存快照查询和稀疏合成图拓扑分析，减少哈希碰撞查询开销与临时对象分配。

Minecraft 1.20.1 / Forge；配套 AE2 Lightning Tech 2.1.4。

## English

- Fixed an ElementalCraft compatibility crash when entering a world (`IncompatibleClassChangeError: ... must be Methodref constant`) by limiting EJECT interception to block entities instead of the shared Forge capability superclass.
- Improved certified direct-route fallback selection for small crafting graphs while respecting cancellation and planning time limits.
- Reduced inventory snapshot lookup overhead and temporary allocations during sparse crafting graph topology analysis.

Minecraft 1.20.1 / Forge; accompanies AE2 Lightning Tech 2.1.4.
